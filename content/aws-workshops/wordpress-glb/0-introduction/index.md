您将学习利用亚马逊云科技的资源来部署一个 WordPress站点。要配置此 WordPress 站点，您将根据如下的架构图，在云中创建以下资源：

- [Amazon Virtual Private Cloud](https://aws.amazon.com/cn/vpc/) (Amazon VPC)，用于将 Amazon 资源启动到您定义的虚拟网络中；
- [Amazon EC2](https://aws.amazon.com/cn/ec2/) 实例，用于安装和托管 WordPress 应用程序；
- [Amazon RDS for MySQL](https://aws.amazon.com/cn/rds/mysql/) 数据库，用于存储您的 WordPress 数据。




{{% workshop-alert type="info" %}}
请确保您拥有所需服务的完全访问权限。如果您在账号创建方面存在问题，请联系您的销售顾问。如果您的账号缺少所需服务的权限，请联系您账号所属组织的管理员。
{{% /workshop-alert %}}
