本次动手训练营会介绍UE4像素流送在Amazon G4dn 实例上的容器化部署方案。在本次动手训练营中在您会了解到如何在G4dn实例上安装并创建UE4项目。同时构建docker镜像，通过docker-compose 实现在亚马逊云上的部署，并进行像素流推送。

#### 本次动手训练营的主要内容

1. 使用 G4dn实例在Windows环境中安装UE 4.27，创建演示项目
2. 使用 G4dn实例在Linux 环境中编译UE4演示项目，构建演示项目的docker image
3. 在Linux环境中使用docker-compose 部署服务器和UE4演示项目
4. 通过浏览器/移动终端访问UE4演示项目
