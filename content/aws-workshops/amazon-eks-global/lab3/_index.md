# 

在此任务中，您将在已创建的集群上的容器中部署简单的Web应用。

在完成应用之后，您可以通过负载均衡器的DNS连接到该Web应用，并观察到Amazon Elastic Load Balancer 负载均衡器在各个节点之间的流量变化。 您将拥有一个应用程序，该应用程序包含三个运行前端网站服务的容器和三个关于该应用的展示效果。
