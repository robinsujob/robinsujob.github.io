欢迎参加本次动手训练营！ 

本次动手实验您将了解如何通过SAM - Serverless Application Model，在 AWS 上构建无服务器应用。同时您还将了解如何将已有的Java、Python等应用通过Lambda Web Adapter迁移至Lambda上。

[AWS Serverless Application Model](https://aws.amazon.com/cn/serverless/sam/) (AWS SAM) 是一个开源框架，用于使用基础设施即代码 (IaC) 构建无服务器应用程序。

[AWS Lambda Web Adapter](https://github.com/awslabs/aws-lambda-web-adapter)  允许开发人员使用熟悉的框架（例如 Express.js、Next.js、Flask、SpringBoot、ASP.NET 和  Laravel，任何支持 HTTP 1.1/1.0 的框架）构建 Web 应用程序 (http api) 并在 AWS Lambda 上运行。 相同的 docker 映像可以在 AWS Lambda、Amazon EC2、AWS Fargate 和本地计算机上运行。
