# 
Amazon Elastic Kubernetes Service (Amazon EKS) 是一项托管服务，可让您在 AWS 上轻松运行 Kubernetes，而无需安装、操作或维护您自己的 Kubernetes 控制面板或节点。Kubernetes 是一个用于实现容器化应用程序的部署、扩展和管理的自动化的开源系统。

#
在本次动手训练营中，您将基于亚马逊云服务完成以下任务：

- 创建堡垒机以用于后续创建EKS集群
- 创建三节点的EKS集群
- 部署单节点的应用
- 扩展应用为三节点
